# To shades of gray

Simple python script to take rbga png images to grayscale png images.

## dependencies : 
-  [numpy](https://numpy.org/)
-  [scikit image](https://scikit-image.org/) 

## Example files taken from : 

[desert](https://opengameart.org/content/desert-tileset-0)   
[outdoor](https://opengameart.org/content/outdoor-tiles-again)
